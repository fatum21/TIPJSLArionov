# Контрольная работа 1. Основы JavaScript

Решения практических работ ПР1, ПР2 и ПР3 и проверки для контрольной работы.

[![Проверки](https://github.com/fatum21/TIPJSLArionov/actions/workflows/checks.yml/badge.svg)](https://github.com/fatum21/TIPJSLArionov/actions/workflows/checks.yml)

Репозиторий: <https://github.com/fatum21/TIPJSLArionov>

## Что где лежит

```
TIPJSLArionov/
├── src/
│   ├── progress.js        ПР1. Сводка выполнения задач, функция summarizeProgress
│   ├── tasks.js           ПР2. demoTasks, getPendingTasks, setTaskCompleted
│   ├── index.html         ПР3. Разметка приложения "Список задач"
│   ├── styles.css         ПР3. Стили приложения
│   └── app.js             ПР3. Фильтры, сводка и переключение статуса
├── checks/
│   ├── check1.js          проверка задания 1
│   ├── check2.js          проверка задания 2
│   ├── check3.js          проверка задания 3
│   ├── selftest.js        самопроверка всех требований, 82 проверки
│   ├── shot_console.js    скриншоты 1, 2 и 3 из реального вывода консоли
│   └── shot_app.js        сценарий Playwright для скриншота 4
├── screenshots/           скриншоты 1, 2, 3 и 4
├── .github/workflows/     автозапуск проверок в GitHub Actions
└── README.md
```

## Как запускать

```bash
node checks\check1.js       задание 1
node checks\check2.js       задание 2
node checks\check3.js       задание 3
node checks\selftest.js     все требования сразу
```

Приложение открывается двойным щелчком по файлу `src\index.html`.
Скрипты обычные, без модулей и сборки, сервер не нужен.

Те же проверки автоматически запускаются в GitHub Actions при каждом
push в ветку `main` и при каждом pull request.

| 2. Отбор | `getPendingTasks([])` даёт `[]` | сходится |
| 2. Отбор | новый массив, порядок и данные сохранены | сходится |
