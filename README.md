## О проекте

Цель работы — закрепить основы JavaScript на примере обработки данных и небольшого интерактивного веб-приложения. Решение развивается последовательно: от отдельной функции для расчёта сводки до работы с массивом задач и интерфейса в браузере.

В проекте используются стандартные возможности JavaScript, HTML и CSS. Для запуска приложения не требуются сборщик, сторонние библиотеки или отдельный сервер.

## Практические работы

| Работа | Содержание | Основные файлы |
|---|---|---|
| **ПР1. Сводка выполнения** | Расчёт количества выполненных и оставшихся задач, процента выполнения и текстового статуса. | `src/progress.js` |
| **ПР2. Работа с задачами** | Демонстрационный набор задач, получение невыполненных задач и изменение статуса задачи. | `src/tasks.js` |
| **ПР3. Браузерное приложение** | Интерфейс списка задач, фильтрация, сводная информация и переключение статуса выполнения. | `src/index.html`, `src/styles.css`, `src/app.js` |

### ПР1 — Сводка выполнения задач

Реализована функция `summarizeProgress`. Она формирует сводку по общему количеству задач и количеству выполненных задач. Проверяются обычные значения, пустой список, некорректные входные данные и граничные случаи.

### ПР2 — Операции над задачами

Подготовлен массив `demoTasks` и функции для работы с ним:

- `getPendingTasks` — возвращает невыполненные задачи;
- `setTaskCompleted` — изменяет статус задачи с указанным идентификатором.

Проверяется корректность результата, сохранение исходного массива там, где это требуется, и обработка отсутствующего идентификатора.

### ПР3 — Приложение «Список задач»

Функции предыдущих работ используются в браузерном интерфейсе. Пользователь может просматривать задачи, выбирать фильтр, отмечать задачу выполненной и видеть обновлённую сводку.

## Приложение «Список задач»

Приложение находится в каталоге `src/`.

**Возможности:**
- отображение списка задач;
- фильтрация задач по состоянию;
- изменение статуса выполнения;
- пересчёт общей сводки и процента выполнения после изменения данных.

Для демонстрации подготовлен набор из четырёх задач с идентификаторами 1, 4, 7 и 10. В исходном наборе выполнены задачи 1 и 10.

## Запуск и проверка

### Требования

- Node.js — для запуска проверочных JavaScript-файлов;
- современный браузер — для работы с веб-приложением.

Установка npm-пакетов и сборка проекта не требуются для запуска самого приложения.

### Запуск приложения

Откройте файл `src/index.html` в браузере — например, двойным щелчком по файлу в проводнике.

### Запуск отдельных проверок

Из корневого каталога репозитория выполните:

```bash
node checks/check1.js
node checks/check2.js
node checks/check3.js
```

### Полная самопроверка

Для запуска общего набора проверок:

```bash
node checks/selftest.js
```

Самопроверка включает **82 проверки** требований проекта.

### Автоматическая проверка на GitHub

В репозитории настроен GitHub Actions. Workflow из файла `.github/workflows/checks.yml` запускает проверки при отправке изменений в ветку `main` и при создании pull request. Текущее состояние отображается значком в начале README.

## Результаты проверок

В таблице приведены контрольные сценарии, предусмотренные проверками проекта.

| Раздел | Проверяемый сценарий | Ожидаемый результат |
|---|---|---|
| ПР1 | `summarizeProgress(12, 5)` | Осталось 7 задач, прогресс 41,7 %, статус «В работе» |
| ПР1 | `summarizeProgress(0, 0)` | Сообщение «Задач пока нет» |
| ПР1 | Выполненных задач больше, чем всего задач | Ошибка вместо обычной сводки |
| ПР1 | Строковые значения и граничные значения | Входные данные проверяются, допустимый диапазон соблюдается |
| ПР2 | `getPendingTasks(demoTasks)` | Идентификаторы невыполненных задач: 4 и 7 |
| ПР2 | `getPendingTasks([])` | Пустой массив |
| ПР2 | Работа с исходным массивом | Порядок и данные исходных задач не нарушаются |
| ПР2 | Изменение статуса существующей задачи | Статус результата изменён, исходный объект не изменён |
| ПР2 | Изменение задачи с id 777 | Операция отклоняется без изменения данных |
| ПР3 | Фильтр «В работе» после выполнения задачи с id 4 | В списке остаётся задача с id 7 |
| ПР3 | Сводка для демонстрационного набора после изменения статуса | Всего 4, выполнено 3, осталось 1, прогресс 75 % |

Подробные условия и assertions находятся в файлах каталога `checks/`. Для повторного получения фактического результата запустите команды проверки из предыдущего раздела.
