Учебный проект по дисциплине «Технологии индустриального программирования». Репозиторий объединяет три практические работы: расчёт сводки выполнения, операции над массивом задач и браузерное приложение «Список задач».

## О контрольной работе

Работа демонстрирует последовательное применение базовых возможностей JavaScript: функции и проверка входных данных, массивы объектов, неизменяемое обновление данных, работа с DOM и обработка событий в браузере.

## Практические работы

| Работа | Содержание | Результат |
|---|---|---|
| [ПР1](./practice-01/) | Сводка выполнения задач | Функция `summarizeProgress` |
| [ПР2](./practice-02/) | Отбор и изменение задач | `getPendingTasks`, `setTaskCompleted` |
| [ПР3](./practice-03/) | Браузерное приложение | Интерактивный список задач |

Каждая папка практической работы содержит собственный README с целью, описанием реализации, запуском и контрольными сценариями.

## Запуск

Для запуска проверок требуется Node.js, для приложения — современный браузер. Установка зависимостей и сборка основного приложения не требуются.

Команды выполняются из корня репозитория:

```bash
node checks/check1.js
node checks/check2.js
node checks/check3.js
node checks/selftest.js
```

Браузерное приложение: откройте [practice-03/index.html](./practice-03/index.html).

## Проверки и результаты

В каталоге [checks](./checks/) находятся отдельные проверки ПР1–ПР3, общая самопроверка и сценарии подготовки скриншотов.

Общий набор самопроверки содержит 82 проверки. Чтобы получить актуальный результат на своей машине, выполните `node checks/selftest.js`. Автоматические проверки запускаются GitHub Actions при push в `main` и при pull request.

## Отчёт и материалы

Отчёт Word перенесён в папку [docs](./docs/) под именем [report.docx](./docs/report.docx); содержимое документа сохранено без изменений. Скриншоты проверок — в [screenshots](./screenshots/).

В качестве образца структуры и оформления использованы принципы учебного репозитория [adyshkins/TIP-JS](https://github.com/adyshkins/TIP-JS): обзор проекта, навигация, отдельные разделы практик, команды запуска, проверяемые результаты и дерево файлов. Содержание адаптировано к фактическим заданиям этой контрольной работы.
