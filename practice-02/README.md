# Практическая работа № 2 — Работа с массивом задач

## Цель работы
Закрепить работу с массивами и объектами JavaScript: отбирать невыполненные задачи и изменять состояние выбранной задачи без мутации исходных данных.

## Реализация
Основной файл — [tasks.js](./tasks.js).

В файле определён демонстрационный массив `demoTasks` и функции:
- `getPendingTasks(tasks)` — возвращает новый массив невыполненных задач;
- `setTaskCompleted(tasks, id, completed)` — создаёт обновлённый массив и новый объект изменённой задачи;
- вспомогательные функции проверяют структуру массива, идентификатор и булев статус.

## Запуск
Из корня репозитория:

```bash
node checks/check2.js
node checks/check3.js
node checks/selftest.js
```

## Контрольные сценарии
| Сценарий | Результат |
|---|---|
| `getPendingTasks(demoTasks)` | Идентификаторы `[4, 7]` |
| `getPendingTasks([])` | Пустой массив |
| `setTaskCompleted(demoTasks, 4, true)` | Новый массив; исходная задача остаётся без изменений |
| `setTaskCompleted(demoTasks, 777, true)` | Ошибка: задача не найдена |

## Результаты
Проверки находятся в каталоге [checks](../checks/). Запуск полной самопроверки: `node checks/selftest.js`.

## Вывод
Реализованы операции фильтрации и безопасного обновления массива объектов с проверкой аргументов и сохранением исходных данных.
