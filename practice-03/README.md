# Практическая работа № 3 — Браузерное приложение «Список задач»

## Цель работы
Объединить функции предыдущих практических работ в интерактивном интерфейсе браузера.

## Состав проекта
- [index.html](./index.html) — HTML-разметка приложения;
- [styles.css](./styles.css) — оформление интерфейса;
- [app.js](./app.js) — фильтрация, отрисовка списка и обработка действий пользователя;
- логика сводки подключается из [ПР1](../practice-01/progress.js);
- операции над задачами подключаются из [ПР2](../practice-02/tasks.js).

## Возможности
- просмотр демонстрационного списка задач;
- фильтрация по состоянию выполнения;
- переключение статуса задачи;
- автоматическое обновление сводки и индикатора прогресса.

## Запуск
Откройте файл `practice-03/index.html` в современном браузере. Сборка и отдельный сервер для приложения не требуются.

Проверки из корня репозитория:

```bash
node checks/check3.js
node checks/selftest.js
```

## Проверка в браузере
Сценарий Playwright проверяет фильтр «В работе», переключение задачи с id 4 и обновление сводки. Для повторного создания снимков используется:

```bash
node checks/shot_app.js
```

## Результат контрольного сценария
После выполнения задачи с id 4 в фильтре «В работе» остаётся задача с id 7. Сводка демонстрационного набора: 4 задачи всего, 3 выполнено, 1 осталось, прогресс 75.0 %.

## Вывод
Создано браузерное приложение, объединяющее расчёт сводки, работу с массивом задач и интерактивное управление состоянием.
