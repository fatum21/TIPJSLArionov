# Практическая работа № 1 — Сводка выполнения задач

## Цель работы
Реализовать функцию расчёта сводки выполнения задач и проверить корректность обработки обычных, граничных и ошибочных входных данных.

## Реализация
Основной файл — [progress.js](./progress.js).

Функция `summarizeProgress(totalTasks, completedTasks)` проверяет входные значения и возвращает:
- количество оставшихся задач;
- процент выполнения с одним знаком после запятой;
- текстовый статус;
- сообщение об ошибке для некорректных данных;
- отдельный результат для пустого набора задач.

## Запуск
Из корня репозитория:

```bash
node practice-01/progress.js
node checks/check1.js
node checks/selftest.js
```

## Контрольные сценарии
| Входные данные | Ожидаемый результат |
|---|---|
| `(12, 5)` | Осталось 7, прогресс 41.7 %, статус «В работе» |
| `(0, 0)` | «Задач пока нет» |
| `(5, 6)` | Ошибка: выполненных задач больше общего количества |
| Строки, дробные и отрицательные значения | Ошибка валидации |

## Результаты
Общий набор самопроверки включает 82 проверки. Фактический результат можно повторно получить командой `node checks/selftest.js`; результаты автоматического запуска доступны во вкладке [Actions](../actions).
